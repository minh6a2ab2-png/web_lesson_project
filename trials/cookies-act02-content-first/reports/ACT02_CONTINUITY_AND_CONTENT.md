# ACT02 Cookies — Six-screen continuity and content plan

Source: Cookies Skill08 CV5512 ACT02 and Skill09 v3.4 contract A2-01…A2-06. Keep six IDs and 12 minutes (720 seconds). Skill04 learner profile remains provisional.

| Scene | Primary intention | Main visual/teaching content | Learner's task | Visible connection |
|---|---|---|---|---|
| A2-01 | TEACH/OBSERVE | Why a Browser sends HTTP Request to Server; two actors, one highlighted arrow; recap request/response | Optional point out requester | We will see what server replies |
| A2-02 | TEACH then simple check | Response carries optional `Set-Cookie: language=vi`; annotate each term and value | Choose which direction response goes after seeing terms | Browser receives it; does Browser always store it? |
| A2-03 | EXPLORE | Side-by-side accept/block cases with one control and explicit simulation feedback | Predict and run both outcomes | Only a stored cookie can be considered in later request |
| A2-04 | EXPLORE | Second visit; browser conditionally sends `Cookie: language=vi` in a matching Request | Pick expected result then test, comparison | Compare accepted vs blocked scenarios |
| A2-05 | PRACTISE/COMPARE | Same website and visit diagram with two pathways; a short multiple-choice reasoning task | Explain which case could remember language using this cookie | Hide model and recall the key arrows |
| A2-06 | RECALL | Two empty arrow prompts, optional student-drawn/written/paper answer | Recall `Set-Cookie` and `Cookie` directions without model; reveal only after self-attempt | Next ACT03: how long stored cookie remains valid? |

Clarifications: Cookies are small browser-managed data subject to domain/path/same-site/security conditions; the teaching fixture simplifies to one same-site `language=vi` cookie. A blocked cookie cannot be used for this memory path, but another storage mechanism could remember preferences. The model does not read or set real browser cookies.

## Proposed acceptance
- First-view content explains all terms including `language=vi`; no unexplained raw code.
- Each Next preserves one visible bridge, identical language-choice storyline and clear speaker terms.
- Different layouts for explanation, annotated response, interactive model, conditional return, comparison, retrieval.
- No compulsory text-entry in A2-01/A2-02; purposeful input only in exploration/practice/recall.
- Hints are optional and local to an actual difficulty; no permanent right column.
- All six screens usable with keyboard and screen width 360px; no overflow; no accidental reveal in recall.
