# Quy tắc lưu trữ / Đồng bộ đầu ra Skills

Effective 2026-11-14 by user approval.

For each completed Skill in this project:
1. Produce and test locally; preserve versioned files.
2. Upload complete distributable artifacts (ZIP, PDF, DOCX, media and teacher/student packages) to the correct Google Drive project folder.
3. Commit source/code, text specifications, manifests and handoff to GitHub where available; do not claim archives on Drive are source commits.
4. Read back/check the Drive folder and GitHub paths and report the exact outcome, including exceptions.
5. Never overwrite earlier versions without explicit approval; never place teacher-only answer keys in public GitHub.

This workflow runs **during an active ChatGPT request**. It is not an automatic/background service or continuously running synchronization.
