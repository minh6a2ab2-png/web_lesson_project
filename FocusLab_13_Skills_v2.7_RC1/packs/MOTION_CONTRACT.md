Select minimal runtime: CSS for feedback (100–250ms); native Web Animations API for simple cancellable motion; GSAP only when timeline complexity justifies the dependency and pinned local version passes license and runtime QA. Never require CDN, framework, or user terminal.
Pedagogical motion duration differs from UI feedback. Prototype transmission: 900ms at 1x, 0.5x and 2x alternatives. A message marker is illustrative, not a physical packet nor actual latency. State is authoritative; no automatic advancement. Replay, cancel, reset, input, language and viewport changes preserve correct state. System reduced motion disables positional animation; keep textual and static direction/state. Do not reveal answers early, block navigation, or loop without purpose. Keep audio/video optional.
