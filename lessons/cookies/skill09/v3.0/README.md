# Interactive Learning Studio v3.0 — Cookies

Quyết định của người dùng: giữ 12 Skills; áp dụng 6 mode Presentation, Story, Lab, Dual View, Knowledge Map, Focus & Recall. EXIT độc lập.

## Nội dung
- `Skill09_Architecture_v3.md` — kiến trúc đã chốt ở mức thiết kế.
- `Skill10_Visual_Design_System_v3.md` — design tokens/layout hi-fi định hướng, **chưa hoàn tất Skill10**.
- `Learning_Scene_Contract_v3.json` và `Mode_Scene_Matrix.csv` — đủ 22 scenes và mode mapping.
- `Studio_Prototype.html` + `.css/.js` + `assets/` — demo nhiều chế độ, cần mở cả thư mục.
- `Studio_Standalone.html` — phiên bản một file dễ thử, hình SVG được nhúng.
- `QA_REPORT.md` — kết quả kiểm tra, giới hạn còn lại.
- `Handoff_Asset_Gaps_and_Next_Steps.md` — cần sản xuất asset P0 trước làm web thật.

Không dùng cookie thật, không có teacher answer key, không thay đổi nội dung sư phạm v2.1. Bản demo Lab chỉ mô phỏng deterministic.
