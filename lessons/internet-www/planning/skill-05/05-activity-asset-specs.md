# 05 – Activity Asset Specs (rerun, v3.2)

## Purpose
Produce the lesson resources for 5.1 Internet & WWW as actual files when feasible.

## New rule applied
If a resource can be created accurately in the current ChatGPT workflow, it should be created here rather than left as a design note.

## Ready visual/animated resources
1. `assets/visuals/internet_vs_www.svg` – concept comparison diagram.
2. `assets/visuals/url_anatomy.svg` – URL component diagram.
3. `assets/visuals/rendering_pipeline.svg` – HTML/CSS/JS comparison diagram.
4. `assets/animations/dns_query_flow.gif` – animated explanation of DNS flow.
5. `assets/animations/http_request_response.gif` – animated explanation of HTTP request/response.
6. `assets/browser_offline/` – offline browser practice pages.

## Produced but intentionally not overproduced
- No separate browser simulator: the learner uses real browsers.
- No video file was created because the current resources are better served by SVG and GIF assets; a video would duplicate the same teaching function without adding pedagogical value.

## Still deferred to later implementation
- Interactive DNS lab with case switching and evidence log.
- Interactive HTTP/HTTPS simulator with 200/404 cases and HTTPS reasoning tasks.
- Interactive end-of-lesson journey builder.
